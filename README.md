# lab05-website01
Prompt: Build a Professional Single-Page CV Website

Create a modern, professional, fully responsive single-page CV/Resume website with a clean design, smooth scrolling, and an elegant user interface. The website should showcase my personal information, skills, education, experience, projects, and achievements in a visually appealing way.

1. Design and Style
Use a modern, minimal, premium, and professional design.
Choose a clean color palette, such as navy blue, white, light gray, and a subtle accent color.
Use beautiful typography, consistent spacing, subtle shadows, rounded corners, and smooth hover effects.
Make the website look professional for recruiters, employers, and clients.
Add subtle scroll animations and transitions without making the website slow.
Support both desktop and mobile devices.
Make the design accessible, readable, and easy to navigate.
2. Website Structure

Build the following sections on a single scrolling page:

A. Navigation Bar
My name or personal logo.
Home, About, Skills, Experience, Education, Projects, Certifications, and Contact links.
Clicking a link should smoothly scroll to the corresponding section.
Keep the navigation bar sticky at the top while scrolling.
Include a mobile-friendly hamburger menu.
B. Hero Section
My full name in a large, attractive heading.
My professional title, such as Web Developer, Software Engineer, Graphic Designer, or another relevant profession.
A short professional introduction.
My profile picture with a professional layout.
Two buttons: “Download CV” and “Contact Me”.
Links to my LinkedIn, GitHub, portfolio, or other professional profiles, where applicable.
C. About Me
A short professional biography.
My career goals, interests, strengths, and professional background.
A brief statement explaining what value I can bring to an organization.
D. Skills

Organize skills into clear categories:

Technical skills.
Programming languages and frameworks, if applicable.
Software and tools.
Communication and teamwork.
Problem-solving and other relevant soft skills.

Use clean skill tags, grouped lists, or simple progress indicators. Do not invent skills or proficiency levels.

E. Work Experience

For each job, display:

Job title.
Company name.
Employment dates.
Location or remote status.
Main responsibilities.
Key achievements and measurable results, when available.

Display work experience in a professional timeline or card layout. If I have no work experience, show relevant internships, volunteering, freelance work, or practical experience if provided.

F. Education

Include:

Degree or qualification.
Institution name.
Start and graduation dates.
Relevant coursework, academic achievements, or honors, if applicable.
G. Projects

For each project, include:

Project name.
Short description.
Technologies or tools used.
My role and contributions.
Project screenshot or thumbnail, if available.
Live demo and source-code links, if available.

Make project cards interactive with subtle hover effects.

H. Certifications and Achievements
Professional certifications.
Online courses and training.
Awards, honors, and notable accomplishments.
Relevant workshops or professional development.

Only display information I provide.

I. Additional Information

Include relevant sections when applicable:

Languages spoken.
Volunteer experience.
Publications.
Professional memberships.
Interests or hobbies relevant to my career.

Do not add unnecessary sections just to fill space.

J. Contact Section

Include:

Professional email address.
Phone number, if I choose to share it.
City and country, if relevant.
LinkedIn and GitHub links, where applicable.
A simple contact form with name, email, subject, and message fields.

Add clear validation and helpful success or error feedback. If a backend is not configured, do not pretend the contact form sends messages; provide an appropriate setup or mail link.

K. Footer
My name.
Copyright notice with the current year.
Links to relevant professional profiles.
A “Back to Top” button that smoothly scrolls to the beginning of the page.
3. Scrolling and Interactions
The entire website must be a single page with vertical scrolling enabled.
Use smooth scrolling for navigation links.
Add a sticky navigation bar.
Highlight the active navigation section while scrolling, if practical.
Add subtle fade-in or slide-in animations as sections enter the viewport.
Ensure buttons, links, menus, and interactive elements work correctly.
Respect reduced-motion accessibility preferences.
Avoid unnecessary loading animations and distracting effects.
4. CV Download and Printing
Add a prominent “Download CV” button.
Allow the CV to be downloaded as a PDF using a real provided PDF file or a properly implemented PDF export feature.
Add a print-friendly layout so the CV can be printed clearly.
Never create a fake download button or link to a missing file.
5. Technical Requirements
Use clean, maintainable, well-organized code.
Use semantic HTML and accessible components.
Use CSS Flexbox and Grid for responsive layouts.
Optimize images, fonts, and performance.
Ensure the website works on mobile phones, tablets, laptops, and large screens.
Add appropriate page metadata, a descriptive title, and SEO-friendly descriptions.
Use accessible color contrast, keyboard navigation, and visible focus states.
Avoid horizontal overflow and broken links.
Do not include unnecessary libraries or dependencies.
Keep the website fast, secure, and easy to update.


6. Final Result

Deliver a complete, polished, production-ready single-page CV website with smooth scrolling, professional design, responsive layouts, functional navigation, and all relevant CV sections.

Before finishing, test all navigation links, mobile layouts, buttons, the CV download, form validation, and scrolling behavior. Fix any visible layout issues and broken functionality.

Start by building the complete website, not just a design mockup. If any personal information is missing, use clearly labeled placeholders rather than stopping to ask questions.
